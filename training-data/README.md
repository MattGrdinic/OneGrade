# training-data — reference stills for fitting Look targets

Local working data for `experiments/looks`. **Nothing in here except this file and the
`films.txt` curation lists is committed**, and that split is deliberate rather than a
convenience.

---

## What this is, and what it is not

The Look feature needs to know where a subject's shadows and midtone should sit for a given
look. Today there is one answer to that — `subjFloor 0.125 / subjMid 0.278 /
frameCeiling 0.968` — measured from a single hand-graded interview. This folder holds the
reference pictures those numbers get re-measured from.

**The stills are analysed, never redistributed.** `experiments/looks` reads each image, reduces
it to a handful of percentiles per region, and throws the pixels away. What eventually ships in
the plugin is on the order of eight numbers per look. Measurements of an image are facts about
it, not a reproduction of it, and no image from here goes into the repository, the bundle, or
any release artefact.

That is the reason this is fine — **not** that the frames are unowned. They are stills from
copyrighted films; film-grab.com hosts them but the studios hold the rights. Any use of this
folder beyond local measurement is a different question with a different answer, so do not treat
it as a redistributable corpus, and do not train a generative model on it.

## Tracked vs ignored

| path | committed? | why |
|---|---|---|
| `README.md` | **yes** | so the folder cannot be found later without its provenance |
| `looks/*/films.txt` | **yes** | the curation IS the experiment — see below |
| `looks/*/manifest.tsv` | no | regenerated by the fetcher; records source URL + date per file |
| `looks/*/*.jpg` | no | copyrighted stills, local analysis only |
| `index.tsv` | no | 4,251-row site index, regenerable in five requests |

**The lists are committed because they are the ground truth.** Deciding that *these* thirty films
carry the moody look is an editorial judgement, and it is exactly the judgement the targets get
fitted to. Committing it makes the corpus reproducible by anyone with the repo, while nothing
copyrighted is ever stored. It also keeps faith with the rule that has made every fit in this
project work: fit to the user's taste, not to a convention.

The seeded lists are marked **PROVISIONAL** in their own headers. They are placeholders chosen to
get a first pass running — replace them.

## Gathering

```bash
./experiments/looks/fetch.py index                          # once; 5 requests
./experiments/looks/fetch.py find "blade runner"            # slugs for a films.txt
./experiments/looks/fetch.py get training-data/looks/moody  # download
```

The fetcher rate-limits, identifies itself with a contact address, honours `Retry-After`, and
skips anything already on disk, so re-running costs nothing. film-grab's `robots.txt`
(checked 2026-08-13) disallows only `/wp-admin/`.

## One frame per film, on purpose

The site's image sitemap publishes exactly one still per film, and that is the sampling design
worth having anyway.

Thirty frames from three films is **not** n=30. Same DP, same grade, same scenes — the frames are
strongly correlated, so the within-look spread comes out far too small, and separability is
measured *against* that spread. It would report looks as distinct because the sample was narrow,
which is the same failure the first separability metric had (see `experiments/looks/README.md`).
Thirty frames from thirty films is a real n=30, and costs one request per film instead of thirty.

## Measuring

```bash
cd experiments/looks && make
./looks ../../OneGrade.ofx.bundle/Contents/Resources/Model \
        ../../training-data/looks/cinematic ../../training-data/looks/moody
```

Read `experiments/looks/README.md` for the output. The headline is the separability table: if
looks overlap on every axis, the tone quadruple alone cannot carry them apart and the answer is
more *axes* — the colour/separation triple, or a different print stock per look — not more stills.

## Known gap in the corpus

film-grab is narrative cinema only. **"Corporate interview" cannot be sourced here**, and neither
can most commercial or broadcast looks. Those need a different reference set — a folder of your
own graded work is the better source for them anyway, and is the one that matches how every other
constant in this project was fitted.

## Regenerating from scratch

Everything here is reproducible from the committed lists:

```bash
./experiments/looks/fetch.py index
for d in training-data/looks/*/; do ./experiments/looks/fetch.py get "$d"; done
```
